# ドキュメント作成

対象読者と文書の用途を確認し、実装と該当する仕様に照らして必要な内容を書く。利用手順やコマンドは、確認できる範囲で実際の構成と一致させる。設計判断を記録する場合は、理由と影響範囲を簡潔に示す。

## 禁止事項

- 実装されていない機能や未確認の挙動を、利用可能なものとして書かない。
- 同じ説明を複数文書へ複製して正本を増やさない。既存の正本へリンクするか、必要な箇所だけを更新する。
- 読者の判断に不要な背景、作業経緯、冗長な言い換えで文書を長くしない。
- 実際の秘密情報、個人情報、利用者の実データを例やスクリーンショットに含めない。
- 既存の仕様と矛盾する変更を、理由や対象作業を示さずに加えない。
