# 社内向け接続の仕組み

## トークンの発行
利用部署の申請を受けて、管理コンソールから有効期限 90 日の鍵を作る。鍵は申請者本人にだけ暗号化メールで渡す。

## 失効の手順
退職や漏えいの疑いがある場合は、管理コンソールの一覧で該当の鍵を選び「無効化」を押す。無効化は数分で全サーバーに反映される。

## 呼び出し制限
1 つの鍵につき毎分 600 回までの呼び出しを受け付ける。超過すると 429 を返す。
